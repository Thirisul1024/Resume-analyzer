📄 AI Resume Analyzer

An AI-powered web app that analyzes your resume against a job description and gives instant feedback.

🔍 What it does
- Gives a **match score out of 100**
- Lists your **strengths** for the role
- Finds **missing keywords** recruiters look for
- Gives **3 tips** to improve your resume
  
 🛠️ Built With
- Python
- Streamlit
- Google Gemini AI API

How to Run
1. Clone this repository
2. Install dependencies: `pip install streamlit google-generativeai`
3. Add your Gemini API key in `app.py`
4. Run: `python -m streamlit run app.py`
